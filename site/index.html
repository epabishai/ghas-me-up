What GitHub is watching

  • Dependabot alerts for every pinned dependency across npm, bundler and Go modules
  • Dependabot security updates that open the fix PR for you
  • Code scanning (CodeQL) for JavaScript, Ruby, Go and the Actions workflows themselves
  • Dependency review that blocks risky dependency changes in PRs
  • Secret scanning & push protection before a token ever lands in history
